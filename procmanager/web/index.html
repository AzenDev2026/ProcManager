About

ProcManager desktop process manager

ProcManagerVersion 1.0.0 · Local
127.0.0.1 only 1-second sampling

All data comes from local /proc, /sys and psutil. Memory and disk capacities use 1024-based units, matching Windows Task Manager.

Data notes

Accuracy and what the dashes mean

  • Process CPU is normalized by the number of logical processors and shown as a percentage of total machine CPU, matching Windows Task Manager.
  • Disk I/O and per-process I/O come from kernel counters. Processes owned by other users may show “—” because /proc/[pid]/io is restricted.
  • Network is the combined rate of all non-loopback interfaces. Wi-Fi adapters often do not report link speed, so it is shown as “—”.
  • Memory type/speed needs root access to DMI. When running as a normal user both fields show “—”; this is expected.
  • GPU utilization depends on the driver. Intel Xe does not expose global utilization, so ProcManager shows the requested GPU frequency and labels it clearly.
  • Ending root processes requires running ProcManager as root. ProcManager itself and PID 1/2 are protected.
